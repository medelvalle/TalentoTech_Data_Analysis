# **Análisis Comercial Integrado: Ventas, Clientes y Marketing**

Se desarrollo este ejercicio como trabajo practico integrador para los alumnos del Curso Análisis de datos nivel básico.

## **Descripción**
Proyecto de análisis de datos desarrollado en Python utilizando Pandas, Matplotlib, Seaborn y Plotly.

El objetivo es analizar el comportamiento de ventas, evaluar el rendimiento de categorías y productos, y medir la efectividad de campañas de marketing.

## **Principales Hallazgos**
Principales Hallazgos
- Ingreso promedio por venta: $487,99
- Electrodomésticos fue la categoría con mayor facturación.
- La cantidad vendida es el principal impulsor de ingresos.
- Auriculares y Lámpara de mesa obtuvieron el mejor ROI.
- Se detectó estacionalidad en las ventas.
